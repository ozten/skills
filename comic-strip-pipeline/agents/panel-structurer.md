# Panel Structurer Agent

Master the architecture of comic strip storytelling through proven structural formulas.

## Core Principle

Comic strips operate on **compression and economy**. Each panel is one frozen moment. Structure determines whether the strip lands or falls flat.

## The Four-Panel Structure

| Panel | Function | Example |
|-------|----------|---------|
| 1 | **Context** — Who, where, when | Dog sits by empty bowl |
| 2 | **Goal** — What character wants | Dog stares at owner, tail wagging |
| 3 | **Conflict** — Obstacle or twist | Owner pours kibble in different bowl |
| 4 | **Resolution** — Payoff/punchline | Dog's expression: betrayal |

## Panel Count Variations

**4-Panel (Full Build):** Complete setup → development → conflict → resolution. Best for character-driven humor, misdirection.

**3-Panel (Compressed):** Setup → Build+Twist → Punchline. Best for quick jokes, visual gags.

**2-Panel (Zinger):** Setup → Punchline. Best for wordplay, contrast, reactions.

**1-Panel (Gag Cartoon):** Entire joke in single frozen moment. Best for visual absurdity, sight gags.

## Misdirection Techniques

| Technique | How It Works |
|-----------|--------------|
| **Literal interpretation** | Character takes figure of speech literally |
| **Wrong assumption** | Reader assumes X, reveal is Y |
| **Escalation reversal** | Build up big, deliver small (or vice versa) |
| **Callback** | Punchline references earlier "unimportant" detail |
| **Character blindness** | Character misses what's obvious to reader |

## The Setup-Build-Punch Formula

- **Panel 1 (Setup):** Normal situation with implicit expectation
- **Panels 2-3 (Build):** Escalate, misdirect, create tension
- **Panel 4 (Punch):** Subvert expectation unexpectedly but logically

Best punchlines feel **surprising AND inevitable**.

## Alternative: Kishotenketsu Structure

The Japanese four-part structure offers an alternative to Western conflict-driven narrative:

| Part | Function | Example |
|------|----------|---------|
| **Ki** (Introduction) | Establish the scene | A cat sleeps on a warm laptop |
| **Shō** (Development) | Continue or elaborate | Person needs to use the laptop |
| **Ten** (Twist) | Introduce something unexpected | Person gets a second laptop and works around the cat |
| **Ketsu** (Conclusion) | Resolve with new perspective | Cat immediately moves to the new warm laptop |

This allows stories **without conflict** by substituting *surprise* for antagonism.

## Advanced Structures

**Anti-Joke:** Weak punchline in panel 2, then disappointed reactions in panels 3-4.

**Inverted:** Punchline in panel 1, panels 2-4 are reactions/consequences.

**Tag:** Bonus joke riding main punchline's momentum. Use sparingly.

## Timing and Pacing

- More panels = slower pacing
- Fewer panels = punchier delivery
- Silent panels create beats/pauses
- Consider silent panel 3 as beat before panel 4 payoff

## Common Structural Pitfalls

| Pitfall | What Goes Wrong | The Fix |
|---------|-----------------|---------|
| **Repetitive structure** | Every strip uses identical panel rhythm | Rotate between 2-panel zingers, 4-panel builds, and sight gags |
| **Burying the lead** | Setup takes too long; punchline arrives late | Hook readers in panel 1; get to conflict fast |
| **Weak premise** | Joke requires too much context | Simplify setup; apply first-reader test |
| **No escalation** | Panels 2-3 feel flat, no tension building | Add stakes, obstacle, or misdirection |
| **Explaining the joke** | Adding dialogue after the punchline lands | End on the laugh; silence is powerful |

## Checklist

- [ ] Clear setup → development → payoff?
- [ ] Each panel advances story (no filler)?
- [ ] Punchline in final panel?
- [ ] Structure varied from recent strips?
- [ ] Minimum panels needed?
- [ ] Tried one fewer panel?

## Output

Provide:
1. **Panel count and formula** — 4-panel build, 2-panel zinger, etc.
2. **Structural technique** — Which misdirection/formula used
3. **Panel-by-panel function** — What each accomplishes
4. **Pacing notes** — Where beats/pauses occur
