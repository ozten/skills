# Phase 4: Beachhead Selection

**Goal:** Pick which ICP segment to attack first.

**Skip condition:** If only 1 segment was selected in Phase 2, that segment IS the beachhead. Skip this phase entirely.

## Process

### Step 1: Present Comparison Matrix

Build a comparison across 5 dimensions for each selected segment:

```
### Beachhead Comparison

| Dimension | [Segment 1] | [Segment 2] | (Segment 3 if exists) |
|-----------|-------------|-------------|----------------------|
| Pain intensity | How acute is the pain? (1-5) | | |
| Accessibility | Can you reach 100 of them? | | |
| Willingness to pay | Budget band + urgency | | |
| Competition | How crowded is this niche? | | |
| Your expertise | Do you know this world? | | |

```

**Scoring guide:**

- **Pain intensity:** 5 = "hair on fire," actively searching for solutions. 1 = "nice to have," no urgency.
- **Accessibility:** 5 = they congregate in 1-2 places you can reach cheaply. 1 = scattered, hard to find.
- **Willingness to pay:** 5 = clear budget, paying for alternatives already. 1 = expects free, no precedent.
- **Competition:** 5 = blue ocean, no direct competitors. 1 = red ocean, crowded market.
- **Your expertise:** 5 = you ARE this person or know them deeply. 1 = you're guessing from the outside.

### Step 2: Make an Opinionated Recommendation

Don't just present the matrix — recommend a segment and explain why:

> **I'd pick [Segment X] as your beachhead.** Here's why:
>
> - [Reason 1 tied to a specific dimension]
> - [Reason 2 tied to a specific dimension]
> - [Caveat or risk to watch]
>
> [Segment Y] is a strong second — you could expand there after validating with [Segment X].

**Decision heuristics (in priority order):**

1. **Accessibility wins ties.** If two segments have similar pain, pick the one you can actually reach.
2. **Pain intensity is the tiebreaker.** Between two equally accessible segments, pick the one with more urgent pain.
3. **Your expertise matters more than market size.** A smaller segment you understand deeply beats a large one you're guessing about.
4. **Willingness to pay validates pain.** If they're not paying for alternatives, the pain might not be real.
5. **Competition is usually overweighted.** Don't avoid a segment because competitors exist — competitors validate the market.

### Step 3: User Confirms

> Does [Segment X] feel right as your beachhead? This is where we'll focus channel strategy.
>
> You're not abandoning [Segment Y] — you're just starting somewhere specific.

### Step 4: Record Selection

```
### Beachhead: [Segment X] [✓]

**Why:** [1-2 sentence rationale]
**Expand to:** [Segment Y] after validation
```

### Step 5: Gate Check

**Proceed to Phase 5 when:**
- Beachhead segment is selected

Transition:

> Beachhead locked: **[Segment X]**. Now let's figure out **where to find them and how to reach them**.

Then read `workflows/05-channel-strategy.md` and proceed to Phase 5.

## Anti-Patterns

- **Don't present the matrix without a recommendation.** The whole point is to help them decide, not give them homework.
- **Don't agonize over the scores.** They're directional, not precise. 3 vs 4 doesn't matter — 1 vs 5 does.
- **Don't let "market size" dominate.** At beachhead stage, a focused segment of 1,000 is better than a vague segment of 1,000,000.
- **Don't frame it as permanent.** The beachhead is segment #1, not the only segment ever.
