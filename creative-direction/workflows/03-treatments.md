# Phase 3: Creative Treatments

**Goal:** Generate 3-5 distinct creative treatments, each a complete brand direction. Each treatment is a coherent world — tone, visual mood, messaging, and taglines all reinforce each other.

**References:**
- `references/tone-archetypes.md` — for archetype detail and voice examples
- `references/visual-vocabulary.md` — for describing visual direction precisely
- `references/saas-brand-patterns.md` — for market-appropriate patterns

## Process

### Step 1: Select Archetypes for Treatments

From the 3-5 viable archetypes identified in Phase 2, assign one archetype per treatment. Each treatment explores a different archetype applied to the same product and ICP.

**Ensure maximum contrast:**
- If Treatment A is warm and folksy, Treatment B should be sharp and minimal
- If Treatment A is playful, Treatment C should be authoritative
- Never make two treatments that a user would struggle to tell apart

### Step 2: Generate Treatment Cards

For each treatment, produce a complete card. Every section must be specific enough that a designer or copywriter could *execute from it without asking clarifying questions*.

```
---

### Treatment [N]: [Evocative Name]

**Emotional Territory:** [1-2 words — the core feeling]
**Archetype:** [from references/tone-archetypes.md]

#### Tone of Voice

**In 4 words:** [adj], [adj], [adj], [adj]

| Do Write | Don't Write |
|----------|-------------|
| "[example sentence in this voice]" | "[same idea written wrong for this voice]" |
| "[example sentence in this voice]" | "[same idea written wrong for this voice]" |
| "[example sentence in this voice]" | "[same idea written wrong for this voice]" |

#### Messaging Hierarchy

1. **Primary message:** [The one thing. Max 10 words.]
2. **Supporting proof:** [Why should they believe it? 1 sentence.]
3. **CTA style:** [What the buttons/CTAs sound like — e.g., "Start free" vs "Try it now" vs "See how it works"]

#### Tagline Candidates

1. "[tagline]"
2. "[tagline]"
3. "[tagline]"

#### Headline Examples

> [Headline for landing page hero]

> [Headline for a feature section]

> [Headline for an ad or social post]

#### Visual Mood

- **Color direction:** [Describe the palette mood, not hex codes. E.g., "Warm neutrals — oatmeal, clay, aged paper — with a single high-contrast accent in work-boot orange."]
- **Typography feel:** [E.g., "Rounded sans-serif for headlines — friendly, not childish. Monospace for data/numbers — gives repair logs a ledger quality."]
- **Imagery style:** [E.g., "Real tools, real hands, real properties. Nothing stock-photo glossy. iPhone photos > professional shoots."]
- **Layout energy:** [E.g., "Generous whitespace. One idea per screen. Feels like a clean notebook, not a dashboard."]
- **UI personality:** [E.g., "Big tap targets, minimal chrome. Looks like it was designed for someone wearing work gloves."]

#### Where This Treatment Shines

- **Best channels:** [Which of the GTM channels this voice is strongest on]
- **Best format:** [Long-form content / short social / ads / community posts]
- **Natural habitat:** [Where this brand voice would feel most at home]

#### Risk / Tradeoff

[What you give up choosing this direction. Be honest. E.g., "May feel too casual for Growth-Mode investors if you expand upmarket later."]

---
```

### Step 3: Quality Checks Per Treatment

Before presenting, verify each treatment against:

| Check | Requirement |
|-------|-------------|
| **ICP connection** | Can you point to a specific ICP trait that justifies this tone? |
| **Pain resonance** | Do the headlines address the actual pain, not a generic benefit? |
| **Anti-positioning** | Does this treatment stay within the creative boundaries? |
| **Contrast** | Is this meaningfully different from every other treatment? |
| **Executability** | Could a designer/copywriter work from this without asking questions? |
| **Voice consistency** | Do the taglines, headlines, and do/don't examples all sound like the *same brand*? |

### Step 4: Add Recommendation

After all treatments, state your recommendation clearly:

```
## My Recommendation

**I'd go with Treatment [N]: [Name].**

- [Reason 1 — tied to ICP psychology]
- [Reason 2 — tied to channel fit]
- [Reason 3 — tied to competitive positioning]

Treatment [X] is a strong runner-up if you want [quality it offers that the recommended doesn't].
```

**Recommendation heuristics:**
1. **ICP fit first.** The treatment that most naturally speaks the ICP's language wins.
2. **Channel alignment second.** If the primary channels are community forums, the voice needs to work in casual text, not polished ad copy.
3. **Differentiation third.** The treatment that most clearly separates from current alternatives (spreadsheets, enterprise PM tools) wins ties.
4. **Scalability last.** Can this voice stretch to the secondary segment without a rebrand?

### Step 5: Present All Treatments

Present all 3-5 treatment cards followed by the recommendation. Do NOT ask questions between treatments — present them all at once so the user can compare.

After presenting, transition to Phase 4 (selection).

## Anti-Patterns

- **Don't generate safe, interchangeable treatments.** If you could swap the taglines between treatments and nobody would notice, they're not distinct enough.
- **Don't describe tone — demonstrate it.** The do/don't copy examples ARE the tone definition. The adjectives are just labels.
- **Don't use visual cliches.** "Clean and modern" describes 90% of SaaS. Be specific: *what kind* of clean? *Whose* modern?
- **Don't forget the tradeoff.** Every direction has a cost. Naming it builds trust and helps the user make an informed choice.
- **Don't anchor on the first treatment.** Write the recommendation after all treatments are generated, not before.
- **Don't produce more than 5 or fewer than 3.** The sweet spot is 3-4 for most products. Use 5 only when the positioning is genuinely ambiguous.
