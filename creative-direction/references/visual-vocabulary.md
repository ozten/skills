# Visual Vocabulary Reference

A structured vocabulary for describing visual direction *without producing visuals*. Use these terms to write visual mood descriptions specific enough that a designer could execute from them.

## How to Use This File

When writing the "Visual Mood" section of a treatment card, draw from these vocabularies to be specific. Avoid generic descriptors like "modern" or "clean" — instead combine terms from multiple dimensions below.

---

## Color Direction Vocabulary

Describe palettes by **mood and material**, not hex codes.

### Warm Palettes
| Descriptor | Evokes | Example Materials |
|------------|--------|-------------------|
| Terracotta + sandstone | Earthy, hands-on, grounded | Adobe walls, desert landscape, clay pots |
| Honey + cream | Warm, approachable, domestic | Kitchen light, beeswax, aged paper |
| Rust + charcoal | Industrial, honest, durable | Workshop tools, cast iron, brick |
| Amber + walnut | Rich, established, warm professional | Whiskey, leather, library wood |
| Coral + linen | Friendly, light, inviting | Beach house, cotton, sunrise |

### Cool Palettes
| Descriptor | Evokes | Example Materials |
|------------|--------|-------------------|
| Slate + ice | Sharp, precise, modern | Concrete, glass, winter morning |
| Navy + white | Trustworthy, professional, nautical | Uniforms, institutions, blueprints |
| Forest + fog | Calm, natural, reliable | Pacific Northwest, evergreen, morning mist |
| Steel + mint | Technical, fresh, clinical | Lab equipment, medical, utility |
| Indigo + pearl | Premium, deep, considered | Night sky, high-end packaging |

### Neutral Palettes
| Descriptor | Evokes | Example Materials |
|------------|--------|-------------------|
| Off-white + graphite | Minimal, editorial, restrained | Newsprint, architecture, gallery |
| Kraft + black | Honest, undesigned, practical | Brown paper bags, shop labels, cardboard |
| Concrete + warm gray | Industrial-minimal, urban, grounded | Loft spaces, exposed walls, utility |
| Parchment + ink | Classic, literate, timeless | Notebooks, maps, letterpress |

### Accent Strategy
| Strategy | When to Use |
|----------|-------------|
| **Single bright accent** on neutral base | When the product does ONE thing well — the accent IS the action color |
| **Two-tone** (complementary pair) | When the brand has a clear tension (e.g., warm + sharp) |
| **Monochromatic** with value range | Minimal, premium, restrained brands |
| **Full palette** (3-4 colors) | Playful, energetic, multi-feature brands |

## Typography Feel Vocabulary

Describe type by **personality**, not font names.

### Type Personalities
| Personality | Characteristics | Feels Like |
|-------------|----------------|------------|
| **Workmanlike** | Solid sans-serif, medium weight, wide | Tool labels, road signs, warehouse stencils |
| **Friendly rounded** | Rounded terminals, medium weight | A handwritten note made digital, approachable |
| **Sharp geometric** | Clean geometry, thin to medium weight | Bauhaus, modern architecture, precision |
| **Bookish serif** | Traditional serif, regular weight | Newspaper headlines, legal documents, authority |
| **Slab confidence** | Thick slab serif, heavy | Wanted posters, sports branding, bold statements |
| **Monospace utility** | Fixed-width, any weight | Code editors, receipts, ledgers, typewriters |
| **Humanist calm** | Organic sans-serif, light to regular | Scandinavian design, healthcare, mindfulness |

### Type Pairing Patterns
| Pattern | When to Use |
|---------|-------------|
| **One sans + mono for data** | SaaS with numbers/data (repair costs, dates, amounts) |
| **Serif headlines + sans body** | Authority + readability (content-heavy brands) |
| **One typeface, two weights** | Minimal brands that want consistency over personality |
| **Display + utility** | Bold personality brands — display for impact, utility for info |

### Type Weight Energy
| Weight | Energy |
|--------|--------|
| Light/Thin | Elegant, premium, quiet |
| Regular | Neutral, readable, everyday |
| Medium | Confident, clear, present |
| Bold | Assertive, commanding, urgent |
| Black/Heavy | Loud, playful, maximum impact |

## Imagery Style Vocabulary

### Photography Direction
| Style | Description | Best For |
|-------|-------------|----------|
| **Documentary realism** | Real settings, natural light, imperfect. Shot on an iPhone, not a Hasselblad. | Products for real people in real situations |
| **Styled editorial** | Real subjects but intentionally composed. Clean surfaces, considered props. | Premium-feeling products at accessible prices |
| **Hero product shots** | The product itself (screen, UI) is the star. Floating device mockups or flat screenshots. | SaaS with strong UI, feature-focused messaging |
| **People-first** | Faces, hands, real work happening. The human using the product, not the product itself. | Trust-building, service-oriented, empathy-driven brands |
| **Abstract/metaphorical** | Shapes, textures, materials that evoke the feeling. No product, no people. | Premium brands, abstract value props, enterprise |
| **No imagery** | Type and color only. Let the words and whitespace do the work. | Minimal brands, developer tools, strong-copy brands |

### Imagery Subjects (for physical/real-world products)
| Subject | Evokes |
|---------|--------|
| **Hands at work** | Craftsmanship, doing, making, real |
| **Tools and materials** | Competence, trade, the job itself |
| **Spaces and environments** | Context, lifestyle, aspiration |
| **Before/after** | Transformation, results, proof |
| **Screens in context** | Product in the real world, not in a vacuum |

### Imagery Energy
| Energy | Description |
|--------|-------------|
| **Still** | Composed, quiet, contemplative |
| **Active** | Motion, doing, in-the-moment |
| **Messy-authentic** | Imperfect, real, unpolished on purpose |
| **Polished-aspirational** | Where you want to be, not where you are |

## Layout Energy Vocabulary

### Density
| Level | Description | Best For |
|-------|-------------|----------|
| **Airy** | Generous whitespace, one idea per viewport, room to breathe | Simple products, single-CTA pages, mobile-first |
| **Balanced** | Clear sections, moderate whitespace, 2-3 elements per viewport | Most SaaS landing pages, feature tours |
| **Dense** | Information-rich, multiple columns, lots of content per screen | Dashboards, comparison pages, power-user audiences |

### Rhythm
| Pattern | Description |
|---------|-------------|
| **Hero → cascade** | Big bold opening, then progressively smaller/detailed sections |
| **Even beats** | Equally weighted sections, like a brochure — scroll reveals same-weight cards |
| **Progressive disclosure** | Starts simple, reveals complexity on interaction (clicks, scrolls, toggles) |
| **Single scroll** | One long page, one argument, one flow from top to bottom |

### Grid Personality
| Type | Feels Like |
|------|------------|
| **Strict grid** | Organized, professional, reliable |
| **Broken grid** | Creative, dynamic, personality-forward |
| **Single column** | Focused, editorial, story-driven |
| **Card layout** | Modular, feature-oriented, scannable |

## UI Personality Vocabulary

How the product *interface itself* feels — this bridges marketing visuals and product design.

| Personality | Characteristics |
|-------------|----------------|
| **Tool** | Functional, dense, efficient. Prioritizes speed over beauty. |
| **Notebook** | Clean, personal, paper-like. Feels like a well-organized notebook. |
| **Dashboard** | Data-forward, charts, metrics. Feels like mission control. |
| **Conversation** | Chat-like, step-by-step, guided. Feels like talking to someone. |
| **Invisible** | Gets out of the way. Minimal chrome, maximum content. |
| **Toybox** | Colorful, interactive, delightful micro-interactions. Feels like play. |

---

## Combining Dimensions

A complete visual mood description should touch **all 5 dimensions**:

```
Color + Typography + Imagery + Layout + UI Personality
```

**Example (weak):**
> "Clean, modern design with a professional feel."

**Example (strong):**
> "Kraft + black palette — honest, undesigned, like a shop label. Workmanlike sans-serif for headlines, monospace for costs and dates. Documentary realism imagery — real properties, phone photos, nothing stock. Airy single-column layout, one idea per screen. UI feels like a well-organized notebook — clean fields, big tap targets, nothing hidden behind menus."
