# Comic Strip Editorial Review

Apply professional editorial standards to polish comic strip scripts before artist handoff or publication.

## Core Principle

**Every word, panel, and gutter must earn its place.** If it doesn't advance the story, build the joke, or reveal character, cut it.

## The Five-Category Checklist

Review strips in this order to catch issues systematically.

### 1. Economy

Verify the strip respects format constraints:

- [ ] Total word count under 80?
- [ ] No panel exceeds 25 words?
- [ ] Punchline under 10 words?
- [ ] No balloon longer than 3 lines?
- [ ] Panel descriptions are 1–2 sentences each?

**If any check fails:** Cut ruthlessly. Every word over limit dilutes impact.

**Word count by element:**

| Element | Limit | Current | Status |
|---------|-------|---------|--------|
| Total strip | 50–80 words | [count] | ✓ / ✗ |
| Panel 1 | ≤25 words | [count] | ✓ / ✗ |
| Panel 2 | ≤25 words | [count] | ✓ / ✗ |
| Panel 3 | ≤25 words | [count] | ✓ / ✗ |
| Panel 4 | ≤25 words | [count] | ✓ / ✗ |
| Punchline | ≤10 words | [count] | ✓ / ✗ |

### 2. Visual Storytelling

Verify the art and words work together, not against each other:

- [ ] Removed all dialogue that describes what the art shows?
- [ ] Used silence where it would be more powerful than words?
- [ ] Each panel advances the story (no filler panels)?
- [ ] The strip works for a first-time reader?
- [ ] No "double writing" (script and art saying the same thing)?
- [ ] Visual moments chosen for maximum impact?

**Double writing test:** For each line of dialogue, ask:
- Does the art already show this?
- If I removed this dialogue, would the panel still work?

**Examples of double writing to cut:**

| Don't Write | Why | Do Instead |
|-------------|-----|------------|
| "I'm so angry!" | Expression shows anger | Let the art speak; maybe silent panel |
| "The dragon is huge!" | Art shows dragon scale | "Run!" or silence |
| "I'm opening the door" | Art shows the action | No dialogue needed |

### 3. Character Voice

Verify each character sounds distinct and authentic:

- [ ] Each character has distinct speech patterns?
- [ ] Dialogue sounds natural when read aloud?
- [ ] Used contractions appropriately?
- [ ] No character sounds like you, the writer?
- [ ] Character dialogue can't be swapped without breaking voice?

**Character voice test:** Cover the character names. Can you still tell who's speaking?

**Voice differentiation markers:**

| Character | Vocabulary | Rhythm | Signature |
|-----------|------------|--------|-----------|
| [Name] | [formal/casual/technical] | [short/long sentences] | [optional tic] |
| [Name] | [formal/casual/technical] | [short/long sentences] | [optional tic] |

**Read-aloud test:** Record yourself reading all dialogue. Listen for:
- Stumbles (unnatural phrasing)
- Too many syllables
- Missing contractions
- Lines that don't sound like human speech

### 4. Structure

Verify the strip follows proven structural formulas:

- [ ] Clear setup → development → payoff structure?
- [ ] Punchline/payoff lands in the final panel?
- [ ] Structure varied from previous strips?
- [ ] Used minimum number of panels needed?
- [ ] Tried writing it with one fewer panel?
- [ ] Hook readers in panel 1?

**Structure verification:**

| Panel | Function | Does It Deliver? |
|-------|----------|------------------|
| 1 | Context/Setup | ✓ / ✗ |
| 2 | Development/Goal | ✓ / ✗ |
| 3 | Complication/Build | ✓ / ✗ |
| 4 | Payoff/Punchline | ✓ / ✗ |

**Punchline position test:**
- Is the punchline in the final panel? [ ]
- Is it the final balloon? [ ]
- Is it the final sentence? [ ]

### 5. Craft

Verify professional execution:

- [ ] The strip is funny/moving even without the art?
- [ ] First-time readers can understand it?
- [ ] No exposition that should be shown visually?
- [ ] Punchline feels surprising yet inevitable?
- [ ] Setup is compressed, payoff is clear?
- [ ] Each panel description specifies one frozen moment?
- [ ] Panel descriptions are technical, not prose?

**The First-Reader Test:** Every strip must work for someone who has never seen your characters before. If a new reader can't understand and enjoy the strip, rewrite it.

## Common Pitfalls

Scan for these recurring problems:

| Pitfall | What Goes Wrong | The Fix |
|---------|-----------------|---------|
| **Overwriting** | Text crowds the art; readers lose interest | If dialogue exceeds 25% of panel space, cut it |
| **Double writing** | Script and art say the same thing | Delete any dialogue that describes visible action or emotion |
| **Talking heads** | Strip becomes a wall of dialogue with static characters | Show action between lines; use silent panels |
| **Cramming** | Too much story in too few panels | One frozen moment per panel; trust closure |
| **Repetitive gags** | Every strip uses identical structure | Rotate between 2-panel zingers, 4-panel builds, and sight gags |
| **Weak premise** | Joke requires too much context | Apply first-reader test; simplify setup |
| **Micromanaging art** | Script specifies every pose, expression, detail | Describe only story-critical elements; trust the artist |
| **Burying the lead** | Setup takes too long; punchline arrives late | Hook readers in panel 1; get to conflict fast |
| **No distinct voices** | All characters sound the same | Each character needs unique vocabulary and speech rhythm |
| **Explaining the joke** | Adding dialogue after the punchline | End on the laugh; silence is powerful |

## Red Flag Phrases

If you find these in your script, investigate:

| Phrase | What It Signals | Action |
|--------|-----------------|--------|
| "I'm so [emotion]" | Double writing emotion shown in art | Cut dialogue; trust the art |
| "As you know..." | Exposition disguised as dialogue | Find visual way to show information |
| "Let me explain..." | Setup taking too long | Compress or cut |
| "What I meant was..." | Overexplaining | End on the laugh |
| "Look at..." | Pointing to what art already shows | Delete; readers can see |

## Panel Efficiency Test

For each panel, verify:

1. **Does this panel advance the story or joke?**
   - If no: delete it

2. **Can this information be shown in the art instead of told in dialogue?**
   - If yes: cut dialogue, enhance art description

3. **Would cutting this panel break the strip?**
   - If no: delete it

4. **Could this panel be combined with another?**
   - If yes: consider compression

## The "One Fewer Panel" Exercise

**Mandatory discipline check:** Before finalizing any strip, rewrite it with one fewer panel.

- 4-panel → 3 panels
- 3-panel → 2 panels
- 2-panel → 1 panel

Sometimes the shorter version is stronger. Even if you keep the longer version, this exercise reveals what's truly essential.

## Comparative Review

Compare against your recent work:

- [ ] Is this strip using the same structure as the last 3 strips?
- [ ] Is the joke type (wordplay, visual, character) varied from recent strips?
- [ ] Is the panel count varied from recent strips?
- [ ] Is the pacing (slow build vs. quick zinger) varied?

**Variety is essential.** Readers notice patterns. If your last 5 strips all used 4-panel builds with panel-4 punchlines, switch to a 2-panel zinger or visual gag.

## Pre-Submission Checklist

Before considering the strip finished:

### Critical Requirements
- [ ] Works for a first-time reader?
- [ ] Each character has distinct voice?
- [ ] Punchline is the last thing the reader sees?
- [ ] Showed instead of told wherever possible?

### Format Compliance
- [ ] Word count: Total ≤80, panels ≤25, punchline ≤10?
- [ ] No balloon exceeds 3 lines?
- [ ] Panel descriptions are 1–2 sentences?

### Quality Markers
- [ ] Tried writing it with one fewer panel?
- [ ] Read aloud—does dialogue flow naturally?
- [ ] Removed all double writing?
- [ ] Structure varied from recent strips?

### Technical Polish
- [ ] Characters positioned in speaking order (left speaks first)?
- [ ] Each panel specifies one frozen moment?
- [ ] Shot types indicated for all panels?
- [ ] SFX noted where needed?

## Revision Priorities

If time is limited, fix issues in this order:

1. **Economy violations** (word count over limits)
2. **Double writing** (dialogue duplicating art)
3. **Weak/late punchline** (not in final position or too wordy)
4. **First-reader confusion** (strip doesn't work for newcomers)
5. **No character voice distinction** (everyone sounds the same)
6. **Structural repetition** (using same formula every strip)

## Output Format

After completing editorial review, provide:

### Review Summary
1. **Economy status** — Word counts and compliance
2. **Critical issues found** — Double writing, voice problems, structural issues
3. **Revisions made** — What changed and why
4. **Remaining concerns** — Any unresolved issues or judgment calls

### Revised Strip
Provide the polished version incorporating all fixes.

### Comparison (if helpful)
Before/after examples of significant changes.

## Quick Reference

**Five Categories:**
1. Economy — Word counts within limits
2. Visual storytelling — Show, don't tell; no double writing
3. Character voice — Distinct, natural speech
4. Structure — Clear setup → payoff; varied from recent work
5. Craft — First-reader test; one-fewer-panel exercise

**Before finalizing:**
1. Does it work for a first-time reader?
2. Does every character sound distinct?
3. Can I tell this in one fewer panel?
4. Is the punchline the last thing the reader sees?
5. Did I show instead of tell?

**Red flags:**
- "I'm so [emotion]"
- "As you know..."
- "Let me explain..."
- Word count violations
- Same structure as last 3 strips
